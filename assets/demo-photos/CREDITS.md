# デバッグ・テスト用の写真素材

デバッグモードと自動テストで使う画像は、すべてこの100枚の写真から作っています（プログラムで描いた画像は使いません）。
すべて [Unsplash](https://unsplash.com) から、[Unsplash License](https://unsplash.com/license) の写真を1枚ずつダウンロードし、
長辺1280pxの WebP に縮小したものです（Unsplash+ の写真は含みません）。

## 使っているところ

- デバッグモードのダミー投稿（今日のお題に合う写真を優先。キャプションに撮影者名を表示）
- イベントのマスを埋める写真（マスの色に近い写真）
- テスト用ユーザーのアイコン
- 疑似カメラの映像（写真をゆっくり動かしたもの。イベントでは担当の色に近い写真）
- サンプルのRAW（DNG）: #16「湖の朝」をリニアRGBの DNG に変換したもの（撮影情報は RAW 現像の画面の確認用の値）
- 表示テンプレートの見本（`public/samples/sunset-sea.jpg`）: #3「海に沈む夕日」
- 自動テストで投稿する写真（`e2e/fixtures/photo.jpg`: #1「夏の入道雲」、`red.jpg`: #24「赤の中の一輪」、`sample.dng`、
  `tests/support/factories.ts`、自己診断）

Unsplash License では撮影者の表記は必須ではありませんが、感謝を込めて記載します。

> テスト・動作確認用のデータです。一般の利用者に向けたコンテンツとしては使いません。
